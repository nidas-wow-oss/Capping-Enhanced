# Capping Enhanced

Battleground timers for World of Warcraft 3.3.5a (WotLK): node and flag timers, queue and entry timers, the Wintergrasp timer and a narrow map mode.

Based on **Capping** by **TotalPackage**. All credit for the original addon goes to its author.

## What this version does differently

- Lighter outside battlegrounds: the per-battleground logic only runs once you enter a battleground or Wintergrasp, and the options panel is built the first time you open it.
- Less idle work: the narrow map check only runs in narrow mode, and Wintergrasp polling is much less frequent.
- Several bug fixes (queue handling, per-character profile reset, French start warning, Alterac Valley sync).

## Installation

1. Download this repository (**Code → Download ZIP**).
2. Copy the `Capping` folder into `World of Warcraft/Interface/AddOns/`.

## Usage

`/capping` opens the options.
